# Business case: Support Triage

Generated by `cp experiment-report`. Rates and model cost are `MEASURED` on the
frozen evaluation set. Every other input is an `ASSUMPTION` from
`configs/business_model.yaml`, so every money figure below is an `ASSUMPTION`.
Replace the assumptions with your organization's numbers before relying on them.

## Assumptions

| Input | Value | Justification |
|---|---|---|
| monthly_volume | 50,000 cases per month `ASSUMPTION` | A mid-sized retail bank's written support queue (chat and secure messages). Chosen to make per-case economics visible, not taken from any real bank. |
| manual_handling_minutes | 3.0 minutes per case `ASSUMPTION` | Time for an agent to read a message, pick the queue, and tag it without help. Triage only; resolving the request is out of scope and unchanged by this system. |
| review_minutes | 1.0 minutes per case `ASSUMPTION` | Time for an agent to confirm or correct a suggested route. Shorter than manual handling because the suggestion and the policy reason are shown. |
| loaded_labor_rate | 45.0 USD per hour `ASSUMPTION` | Fully loaded cost of a support agent, including benefits and overhead. Placeholder for a figure finance would supply. |
| misroute_cost_standard | 8.0 USD per wrong auto route `ASSUMPTION` | Rework when a standard request lands in the wrong queue: a second agent touch, a transfer, and a slower resolution. |
| misroute_cost_sensitive | 150.0 USD per wrong auto route `ASSUMPTION` | A fraud or lost-card report that sits in the wrong queue risks further losses, reimbursement, and complaint handling. Deliberately high; sensitive cases should never auto-route under the policy, so this mostly prices residual risk. |
| infrastructure_monthly | 400.0 USD per month `ASSUMPTION` | Allocation for hosting, storage, monitoring, and on-call share for one managed app. Not a quote; M6 measures actual GCP spend for the demo deployment. |

Net monthly value = labor saved on correct auto routes − misroute costs on wrong
auto routes − review labor − model cost − infrastructure. An abstained case falls
back to the manual process at no extra cost.
